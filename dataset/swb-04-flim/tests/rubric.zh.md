# 无工具纯结果评分标准 总分100
## 得分模块1：关键结果准确性（55分，核心权重，误差收紧）
### 1.1 荧光寿命τ时序定量精度（16分）
16分：全像素τ与标准答案偏差≤0.03ns，附带单像素拟合误差列，低信噪比像素置信标记完整；
9分：τ偏差0.03~0.08ns，置信标记缺失10%以内像素；
3分：τ偏差＞0.08ns，无像素置信度标记；
0分：无有效tau_timeseries.txt输出。

### 1.2 膜电位Vm校准与分层筛选（17分）
17分：自主插值拟合R²≥0.99，双重动态掩码完整，饱和失真像素全部标记，Vm误差≤20mV；
10分：拟合R²介于0.92~0.99，仅静态电位筛选，缺失饱和失真标记；
4分：拟合相关性低于0.92，无分层置信标记；
0分：未使用calibration_kv.txt完成校准映射。

### 1.3 动作电位漂移校正+复极分层统计（22分）
22分：完全校正±3帧起搏漂移，APD30/APD90比值误差≤0.01，4视野分开统计，晚复极窗口误差≤3ms，组间t检验p值完全匹配；
12分：时序漂移校正不完全，仅全局平均统计，缺失分视野对比；
5分：波形对齐存在≥2帧偏移，晚复极区间识别错误；
0分：无ap_waveform.csv、stat_ap_ratio.csv核心分层结果。

2分：仅全局剔除异常像素，无分层置信输出；
0分：未做任何像素筛选标记。

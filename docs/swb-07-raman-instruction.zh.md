# 任务需求

## 任务背景

给定单层 MoS2 与 Fe 掺杂单层 MoS2 的 Raman 光谱数据，以及 Fe 掺杂样品的磁场依赖和温度依赖 Raman 数据。请从给定数据独立完成定量分析，判断 Fe 掺杂引起的主要谱学变化、外磁场下的 Raman 响应以及低频连续散射的温度演化，并给出相互一致的物理结论。

所有定量结果必须由给定数据重新计算得到，不得直接采用外部文献中已报道的峰位、磁矩或拟合参数。

## 输入数据

`data/` 中包含：

- `sample_comparison.csv`：单层 MoS2 与 Fe 掺杂单层 MoS2 的 Raman 光谱对照数据。
- `field_series.csv`：Fe 掺杂单层 MoS2 在 −7 T 至 +7 T 面外磁场下的圆偏振 Raman 数据。
- `temperature_series.csv`：Fe 掺杂单层 MoS2 在约 12–200 K 的温度依赖 Raman 数据。

圆偏振通道采用 `RL`、`LR`、`LL` 标记。`R` 和 `L` 分别表示右圆偏振和左圆偏振，两个字母按“入射光—散射光检测”顺序记录。`RL`、`LR` 为 cross-circular 通道，`LL` 为 co-circular 通道。

实验采用 633 nm 连续激光和背散射几何。磁场沿样品面外方向，磁场序列在 12 K 测得。Raman 强度为任意单位，不提供统一的绝对强度标定。数据保留正、负 Raman shift。

## 任务目标

1. 比较 MoS2 与 Fe 掺杂单层 MoS2 的 Raman 光谱，识别并定量分析 Fe 掺杂引起的主要谱学变化。

2. 分析 Fe 掺杂样品各可分辨 Raman 响应的磁场与圆偏振通道依赖，提取具有物理意义的场致频率变化，并定量获得有效 phonon magnetic moment。报告关键结果、不确定度及判断依据。

3. 分析低频连续 Raman scattering 的温度演化，提取与低频静态响应相联系的定量表征，并评价所得温度趋势及模型解释的可靠性。

4. 综合样品对照、磁场依赖和温度依赖结果形成物理结论，明确哪些结论由本题数据直接支持，哪些判断仍需要其他实验验证。

## 输出要求

在 `output/` 文件夹下生成：

1. `raman_analysis.png`  
   300 dpi，集中展示支撑上述分析与主要结论的关键 Raman 数据、拟合和定量结果。

2. `fit_results.csv`  
   记录主要定量结果、对应的数据条件、不确定度和单位。

3. `raman_results.md`  
   说明分析方法、主要定量结果、跨数据物理结论及证据边界。

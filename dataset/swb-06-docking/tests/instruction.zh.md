# 任务需求

## 研究背景

本任务模拟一项计算化学期刊的同行评审工作。待评估论文提出一种新的分子生成框架，并报告其在 CrossDocked2020 测试集的 100 个蛋白靶标上接受了系统基准评估，且在多项指标上优于现有方法。

当前无法获得论文全文，现有材料仅包括从论文及其补充材料中提取的原始数据文件。分析应以这些数据为依据，独立评估论文核心主张的证据充分性，并形成结构化审稿报告。

## 研究问题

#### 需要回答的研究问题

在完成下述对接验证（前置任务）的基础上，围绕 Q1-Q5 展开分析。具体分析路径和统计方法应依据数据特征与研究目标确定。

#### 前置任务：独立对接方法学验证

论文的案例研究部分报告了 CDK2 和 ROCK1 两个靶标的特定对接得分与分子属性值，详见 `case_study_molecules.csv` 和 `target_profiles.csv` 中的对应记录。在分析论文提供的完整数据之前，应使用给定的蛋白质结构和配体分子完成独立对接，以建立方法学比较基线。

（1）蛋白质结构准备。从 `cdk2_protein.pdb` 和 `rock1_protein.pdb` 中提取结合位点信息，完成受体预处理。对接盒子的中心和尺寸需基于共晶配体坐标合理确定，并在报告中给出参数选择依据。

（2）配体准备与对接。对所有配体（2个共晶配体加14个测试配体）完成结构处理和对接。使用共晶配体的重对接RMSD评估对接流程的方法学可靠性。

（3）分子性质计算。对所有16个配体，计算八项分子性质：定量类药性估计（QED）、合成可及性评分（SA）、辛醇-水分配系数（LogP）、拓扑极性表面积（TPSA）、氢键受体数（HBA）、氢键供体数（HBD）、sp3杂化碳比例（Fsp3）、可旋转键数（ROTB）。注意各性质的优劣方向和数值量表的差异。

（4）SR 条件初筛。从 `sr_criteria.txt` 解析筛选标准，并对独立对接所得的配体实施筛选。

（5）方法学比对。将独立获得的对接得分、性质值和 SR 通过情况，与论文在 `case_study_molecules.csv` 和 `target_profiles.csv` 中报告的数据进行比较。两组结果的差异将作为后续 Q1–Q5 分析的方法学基线。

#### Q1 — 方法性能与统计显著性

匿名方法中哪些在关键指标上表现最优？这种优势是否具有统计显著性？优势在不同评估指标、不同分析层级（如聚合均值 vs. 单口袋配对）上是否一致？

#### Q2 — 消融与协同效应

论文声称特定组件之间存在“正协同效应”。应依据消融数据独立检验该主张，并评估不同指标间协同模式的不一致性对结论稳健性的影响。若涉及多次独立假设检验，还应处理其对统计推断的影响。

#### Q3 — SR 条件验证

论文采用一套多条件筛选标准（SR）评价分子质量。应解析各项标准，并使用所提供的分子数据进行验证。若数据不完整，应明确区分可验证与不可验证的项目，并说明原因。

#### Q4 — 适用性与抽样偏差

论文声称该方法具有广泛适用性。应依据靶标特征检验这一主张的边界条件，并评估案例研究中的分子能否代表总体性能。结合前置任务的独立对接结果，量化论文报告值与独立计算值之间的一致性。

#### Q5 — 综合审稿意见

基于全部分析（包括前置任务的方法学验证和 Q1-Q4 的数据分析），判断论文最核心的声称是什么？当前数据在多大程度上支持这些声称？按严重程度列出需要警惕的信号。如果只能要求作者补充一组实验，你会选择什么？为什么？

## 任务输入

`data/` 目录下包含两组文件：论文声称的基准测试数据（10个文件），以及可用于独立方法学验证的蛋白质和配体结构文件（4个文件）。

### 论文基准测试数据

| 文件 | 内容简述 |
|:---|:---|
| `benchmark_results.csv` | 匿名化方法（Method_A 至 Method_I）与 Reference 分子在多个评估指标上的表现 |
| `statistical_test_data.txt` | 口袋级别的统计检验结果（半结构化文本） |
| `ablation_results.csv` | 消融实验结果，部分组件以字母代号匿名化 |
| `backbone_comparison.csv` | 替代网络骨架下的对照实验结果 |
| `synergy_analysis.csv` | 特定组件的协同效应统计检验（两个指标） |
| `sr_criteria.txt` | 论文 Methods 章节关于分子筛选标准的英文原文摘录 |
| `case_study_molecules.csv` | 具体靶标上活性分子与生成分子的属性数据 |
| `timestep_analysis.csv` | 不同实验条件下的参数扫描数据 |
| `property_targets.csv` | 模型训练时预设的属性目标值向量 |
| `target_profiles.csv` | 各靶标的元信息 |

数据可能存在格式不规整、缺失值、命名体系不一致等问题——这是从论文补充材料提取真实数据时的常见情况。所有方法名已被匿名化处理，你无法从代号直接推断任何方法的身份。

### 独立验证用结构数据

| 文件 | 内容简述 |
|:---|:---|
| `cdk2_protein.pdb` | CDK2激酶结构域的晶体结构，含共晶配体坐标。可用于定义结合位点 |
| `rock1_protein.pdb` | ROCK1激酶结构域的晶体结构，含共晶配体坐标 |
| `cdk2_active.sdf` | CDK2的共晶配体三维结构 |
| `rock1_active.sdf` | ROCK1的共晶配体三维结构 |
| `test_ligands.sdf` | 14个测试配体分子的三维结构，属性字段标明了靶标归属和类型 |

这些结构文件支持独立于论文数据的分子对接计算，可据此获得一组独立的对接得分和分子性质值。该结果将作为评价论文基准数据可靠性的方法学参照。

## 任务输出

在 `output/` 目录下提交：

### 必须提交

（1）`docking_results.csv` — 独立对接验证的汇总结果。至少包含：配体ID、靶标、对接得分、共晶配体的重对接RMSD。数值保留2位小数。

（2）`property_results.csv` — 独立计算的分子性质汇总表。包含16个配体的八项性质计算值。数值保留2位小数（Fsp3保留3位）。

（3）`sr_screening.csv` — 对自算配体的SR条件逐项判定结果。

（4）`review_report.md` — 结构化审稿报告。至少包含：独立对接方法与验证结果、数据质量审计、方法性能评估与统计验证、消融分析与协同效应检验、SR条件验证、综合审稿意见（对应 Q5）。具体章节划分和呈现顺序应依据数据特征与研究目标确定。

（5）`analysis_script.py` — 完整的、可独立运行的 Python 分析脚本。从 `data/` 读取数据，输出结果到 `output/`。代码应包含清晰的函数定义和注释。需处理数据文件中可能存在的格式问题。

### 图表

生成至少 6 张图，用于支撑审稿报告中的关键论点。具体图表类型和设计由你根据分析需要独立决定，但应覆盖：
- 独立对接验证的方法学质量控制（如RMSD对比、对接得分分布）
- 方法乘指标的综合性能对比
- 消融分析的结果呈现
- 效应量与统计显著性的关系
- SR 条件的验证情况

所有图表需达到科研出版质量。

#### 注意事项

- 不得假设任何匿名方法是"主角"——所有结论必须从数据本身出发
- 各评估指标的优劣方向未在数据中标注——基于领域知识自行判断，并在报告中陈述推理过程
- 不同数据表之间可能存在需要交叉验证的关联——请自行发现和利用
- 统计方法的选择应依据数据特征与研究目标确定，但必须在报告中给出选择理由
- 输出数值保留3位小数，p值保留科学计数法（如1.16×10^-9）
- 所有结论必须附上数据证据
- 部分配体分子的3D构象是计算方法生成的，对接前可能需要构象优化

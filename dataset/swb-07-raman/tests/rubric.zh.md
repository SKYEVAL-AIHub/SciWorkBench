## 评分标准（仅按结果评分）

总分 100 分。只根据考生最终提交的 `raman_analysis.png`、`fit_results.csv` 和 `raman_results.md` 评分，不评价其使用的软件或具体实现。`answer/` 不提供参考图片，考生图片按科学内容和可核查性评分，不比较配色、版式或绘图风格。

本题评分重点是能否识别正确的 Raman 谱学对象、建立自洽的磁场/圆偏振响应关系，并将样品对照、有效 phonon magnetic moment 和低频温度响应组织成科学一致的证据链。不同合理的峰型、背景、拟合窗口或统计指标可以得到略有差异的数值，不要求机械复现某一种参考实现。

### 得分点1——样品对照与关键 Raman 谱学特征（20分）

- **得分标准**：
  - 从完整 Raman 数据中识别出 Fe 掺杂引起的主要中低频线形变化，并判断 Fe:MoS2 需要比未掺杂 MoS2 更多的谱学分量才能合理描述。（7分）
  - Fe:MoS2 中原有 hybridized mode 应位于约 265 cm⁻¹，参考值 264.92 ± 0.25 cm⁻¹。（4分）
  - Fe 掺杂诱导的额外 Raman 分量应位于约 283 cm⁻¹，参考值 282.86 ± 0.19 cm⁻¹。（5分）
  - 通过残差、模型比较、参数稳定性或其他等价证据说明新增分量具有可重复的谱学依据，而不是仅按局部极大值读峰。（4分）
- **评分边界**：若只分析 380–500 cm⁻¹ 的常规高频 Raman 模而未识别约 265/283 cm⁻¹ 的核心变化，本项不得超过 6 分。

### 得分点2——磁场与圆偏振响应及 branch 判断（25分）

- **得分标准**：
  - 对约 265 cm⁻¹ 和约 283 cm⁻¹ 两套分量均给出跨 −7 T 至 +7 T 的连续、可物理追踪的结果。（8分）
  - 正确识别 RL/LR 对应分量在零场附近的关系，以及磁场反向后圆偏振相关频移的交换关系。（6分）
  - 两套分量的场致频移均可由近似线性关系合理描述，且斜率显著性、残差或不确定度支持该判断。（5分）
  - 能区分真正的圆偏振相关频移与共同漂移、仅强度变化、拟合失败或 branch 身份互换。（4分）
  - 对离群点、参数碰边界或不可稳定追踪的结果有合理处理或明确限制说明。（2分）
- **评分边界**：追踪约 450 cm⁻¹ 高频 Raman 模并据此得出“无磁场响应”，不能替代本题核心 magneto-Raman branch 的分析。

### 得分点3——有效 phonon magnetic moment（15分）

- **得分标准**：
  - 原有约 265 cm⁻¹ 分量的有效 phonon magnetic moment 处于约 2.0–2.5 \(\mu_B\)，参考值为 2.14 ± 0.07 和 2.29 ± 0.07 \(\mu_B\)。（5分）
  - 约 283 cm⁻¹ 新分量的有效 phonon magnetic moment 处于约 2.5–3.1 \(\mu_B\)，参考值为 2.82 ± 0.09 和 2.76 ± 0.06 \(\mu_B\)。（5分）
  - 磁矩定义、单 branch 位移与双 branch splitting 的关系、单位换算和 factor-of-two 保持自洽。（3分）
  - 报告不确定度，并根据误差判断不同圆偏振通道结果是否一致。（2分）
- **评分边界**：因追错 Raman 分量而得到全部接近 0 \(\mu_B\) 的结果，不视为完成本题的有效磁矩提取。

### 得分点4——低频连续散射与温度响应（15分）

- **得分标准**：
  - 从温度依赖 Raman 数据构建与低频静态 susceptibility 相联系的物理量；应包含正确的热占据修正和 Kramers–Kronig \(1/\omega\) 权重，而不是直接积分原始 Raman 强度或普通 \(\int\chi''d\omega\)。（6分）
  - 识别低频 spectral weight 总体随降温增强的主要趋势，并给出合理定量结果。（4分）
  - 使用具有物理依据的温度描述，并以残差、信息准则、参数稳定性或其他等价方式判断其相对于简单替代模型的合理性。（3分）
  - 对低频截止、积分窗口或背景中的至少一项进行敏感性判断，并准确说明有限频率窗口对模型参数的限制。（2分）
- **评分说明**：不把某个特定 Curie–Weiss 温度 \(\Theta\) 作为硬性单值要求。参考有限窗口实现得到负的 \(\Theta\)（约 −20 K 量级），但该参数对窗口和背景存在处理依赖。

### 得分点5——跨数据物理解释与证据边界（20分）

- **得分标准**：
  - 将 Fe 掺杂诱导的额外 Raman 分量、两套圆偏振相关磁场频移、有效 phonon magnetic moment 和低温连续散射组织成相互一致的物理证据链。（8分）
  - 正确理解有效 phonon magnetic moment 表征的是相关 Raman/phonon branch 的磁场耦合尺度，而不是样品静态体磁矩的直接测量。（3分）
  - 对低温连续散射给出与局域磁响应/自旋涨落相容的解释，并与磁场依赖 Raman 结果保持一致。（3分）
  - 正确区分“存在 magneto-Raman 与低频磁性响应”与“已证明某一种零场长程磁有序”。（4分）
  - 明确指出仅凭本题 Raman 数据仍需要独立磁性表征才能确定的磁基态问题。（2分）
- **评分边界**：将 Zeeman-like splitting、有限磁矩或低频连续散射直接等同于铁磁/反铁磁长程有序，应明显扣分。

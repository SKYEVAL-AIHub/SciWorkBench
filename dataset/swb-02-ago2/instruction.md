# AGO2 perturbation and RNA kinetics

Work in `/app` with the supplied `data/` and write your submission to `output/`.

A long-term CRISPRi study found broad expression changes after AGO2 perturbation and suggested that AGO2 acts as a widespread direct transcriptional repressor. Independently assess that claim using the guide-level PerturbSci-Kinetics pseudobulk in `data/ago2_perturbsci_guide_pseudobulk.h5ad`. The supplied metadata describe the guide profiles, RNA layers, study design and upstream records. Use the actual guide profiles and an appropriate control set.

Determine how whole, nascent and preexisting RNA changes relate to one another. Distinguish separate layer normalization from a common-scale decomposition that preserves the additive relationship. Compare AGO2 with other targeting guides, target aggregates and held-out non-targeting control pseudo-queries. Check target engagement, guide quality and whether independent AGO2 guide agreement can be estimated. Use sensitivity analysis and dimensionality reduction to assess robustness. Explain which observations support the mechanism, which alternative explanations remain, and what the data can establish about direct causation. Derive results from the supplied data.

Write the following to `output/`: a full gene-level table `ago2_gene_effects.tsv.gz`, and tab-separated `guide_qc.tsv`, `perturbation_comparison.tsv`, `placebo_calibration.tsv`, `sensitivity_analysis.tsv`, `pca_coordinates.tsv` and `claim_evidence.tsv`. Use stable identifiers (`gene_symbol`, `guide_id`, `target_gene`, `query_id` with `analysis_level`, `configuration`, or `claim` as appropriate). Include `whole_log2_effect`, `nascent_log2_effect`, `preexisting_log2_effect`, `common_scale_total_effect`, `nascent_shapley_contribution` and `preexisting_shapley_contribution` in the gene table, or clearly document an equivalent method and its columns. Include `report.md`, supporting figures, reproducible analysis code and software environment details. The automated verifier compares common fields to reference estimates. The scientific rubric also permits alternative estimators with adequate supporting evidence.

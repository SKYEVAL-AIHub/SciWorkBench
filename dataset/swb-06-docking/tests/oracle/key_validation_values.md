# 参考答案与评分数值参考

本文档供评分参考。分为两部分：第一部分为独立对接验证参考值，第二部分为数据分析核心发现参考（从0721版本保留）。

---

## 第一部分：独立对接验证参考值

### 阳性对照对接

| 配体 | 靶标 | 期望Vina得分范围 | 期望RMSD范围 |
|:---|:---|:---|:---|
| cdk2_active (DTQ) | CDK2 | -9.5 至 -7.5 kcal/mol | 0.5 至 3.5 埃 |
| rock1_active (E9W) | ROCK1 | -11.5 至 -9.0 kcal/mol | 0.5 至 3.5 埃 |

RMSD容差考虑了晶体结构分辨率、对接程序随机性和结构预处理差异。

### 对接盒子参考参数

- CDK2：中心基于DTQ配体几何中心，每维度外扩12-20埃
- ROCK1：中心基于E9W配体几何中心，每维度外扩12-20埃
- 盒子尺寸不应超过35埃（任意维度），超过40埃视为参数异常

### 测试配体对接得分期望

- 所有得分应为负值（表示可结合）。若出现正值，说明对接失败
- CDK2靶标的7个配体得分范围约 -10.5 至 -7.0 kcal/mol
- ROCK1靶标的7个配体得分范围约 -11.0 至 -8.0 kcal/mol
- 对接得分排序应大体与已知活性/非活性分类一致

### 分子性质计算的注意事项

- QED、LogP、TPSA、HBA、HBD、Fsp3、ROTB使用RDKit标准实现
- SA评分：RDKit的sascorer返回1-10量表（1=最易合成），而论文SR条件中SA > 0.59使用的是0-1量表（越高越易合成）。Agent需要识别此量表差异。如果Agent直接使用RDKit原始SA值（6-8范围），则C3对所有分子均Pass（这在数学上正确但在科学逻辑上需要标注）。识别并讨论此差异的Agent表明其对计算化学量表的理解深度
- CDK2共晶配体（DTQ）的Fsp3约为0.125-0.25（取决于RDKit版本和质子化），低于SR条件C6的阈值（Fsp3 >= 0.42）。这意味着阳性对照分子本身不满足SR条件

### SR初筛期望

- C6（Fsp3 >= 0.42）是大多数分子的主要失败原因
- C2（QED > 0.25）极为宽松，几乎所有类药分子均可通过
- C3（SA > 0.59）若使用RDKit原始量表全部通过，Agent需对此进行讨论

## 第二部分：数据分析核心发现参考

### 一、数据质量审计

**指标方向性判定：**

| 指标 | 正确方向 | 推理依据 |
|:---|:---|:---|
| Vina Score | 越低越好 | 结合自由能，负值越大=结合越强 |
| Vina Min | 越低越好 | 局部优化后的结合能 |
| Vina Dock | 越低越好 | 重对接后的结合能 |
| High Affinity | 越高越好 | 优于Reference的分子比例 |
| QED | 越高越好 | 类药性量化评分 |
| SA | 越高越好 | 合成可及性，越高越易合成 |
| Lipinski | 越高越好 | 满足五规则的条数 |
| Diversity | 越高越好 | 生成分子多样性 |

**数据异常：**

| 文件 | 异常 | 严重程度 |
|:---|:---|:---|
| benchmark_results.csv | Reference缺少High_Affinity和Diversity | 低 |
| benchmark_results.csv | Method_C Vina_Score_Avg = +10.50, Method_D = +45.98 | 中 |
| statistical_test_data.txt | 混合科学计数法 | 低（解析难度） |
| case_study_molecules.csv | Vina_Score与Vina_Dock互斥缺失 | 高 |
| timestep_analysis.csv | 首行为#注释行 | 低 |

**方法身份推断：**
Method_I的Vina_Score_Avg = -7.23，与Full_Model（ablation_results.csv）完全匹配。Method_I = Full_Model = 论文方法。

### 二、统计验证核心数值

**显著性筛选：** 仅3个方法pW < 0.05：Method_G（3.13e-4）、Method_H（4.35e-6）、Method_I（1.16e-9）。

**HLE 95% CI完全在0以下：** Method_G [-0.737, -0.053]、Method_H [-1.185, -0.294]、Method_I [-1.316, -0.603]。

**Method_H符号反转：** 聚合均值差 = -0.30（优于Reference），MPD = +0.042（口袋级几乎无差异）。

### 三、消融与协同效应核心数值

**性能退化量（Vina Score）：**

| 变体 | Δ (Variant - Full_Model) |
|:---|:---|
| w/o_S | +1.420 |
| w/o_PQ | +1.380 |
| w/o_V | +1.070 |
| w/o_P | +0.680 |
| w/o_Q | +0.600 |

组件重要性：S > P+Q(联合) > V > P > Q

**P-Q协同效应（Vina Score）：** Synergy = 1.380 - 0.680 - 0.600 = 0.100

**FDR校正后：** 6个指标中仅Vina Score保持显著。SA协同模式为"全有或全无"（P_gain = -0.0393、Q_gain = -0.0323、Both_gain = +0.0121）。

### 四、SR验证核心发现

- C1校准不可行：case study中没有任何分子同时拥有Vina_Score和Vina_Dock
- 活性分子在Fsp3（C6）上系统性失败
- Case Study抽样偏差：每靶标仅1个精选生成分子（来自100个），按最优Vina Score精选的分子在C1上有天然优势
- SA目标值1.0与实际表现0.60差距0.40（全属性最大），SA仅比SR阈值0.59高0.01（全属性最窄边距）

### 五、综合审稿意见参考

**数据支持的结论（示例）：**
- Method_I在Vina Score上排名第一（-7.23），统计显著优于Reference
- 仅Method_G、H、I三个方法显著优于Reference
- 组件S是最大贡献组件（Δ = +1.420）
- P和Q在Vina Score上存在正协同（Synergy = 0.100），经FDR校正后仍显著

**数据不足以支持的结论（示例）：**
- 全维度SR满足：C4-C9聚合均值不可得
- 骨架独立性完整验证：替代骨架缺少w/o_P和w/o_Q独立测试
- Case Study代表性：仅2靶标有完整Vina_Dock、8个可评估分子且为精选

**风险信号排序参考：**
- 第一级：SA边界风险（0.60 vs 0.59，差0.01，采样误差下极易翻转）
- 第二级：SA协同模式异常、FDR校正后多指标协同效应消失、Method_H跨层级符号反转
- 第三级：去噪步数增加导致性能退化、Case Study选择偏差、替代骨架P+Q退化量大幅缩小

**最脆弱的声称（接受任一）：**
- 声称A：全维度SR满足（SA边界仅0.01，C4-C9聚合不可得）
- 声称B：P和Q在多指标上存在正协同（FDR校正后仅Vina Score保持显著）

# 参考答案说明（reference report）

本题要求根据 1H NMR、13C NMR 峰表、NOESY 谱图与 HRMS 实测 m/z 推断三个有机化合物的
结构（compound_C **含立体化学**）并写出 SMILES。本文件说明参考答案、来源核验、判分口径与等价答案规则，
以及判分脚本的自测记录。

- **A（12a）与 B（12b）**：同骨架同系物——多取代脂环（C(Me)(OH) 叔醇位点、并环氧、
  炔丙基侧链 –CH2C≡CH）加一条 (E)-烯酸甲酯侧链；B 比 A 在烯侧链上多一个亚甲基

## 二、参考答案来源与核验

1. **来源**：数据取自 Asian J. Org. Chem. 2024, 13(9)（DOI: 10.1002/ajoc.202400242）
   支持信息（SI）的三页截图（存于原始数据文件夹 `有机分子多维表征5/`），转录化合物
   12a / 12b / 13 的 1H/13C NMR 峰表与 HRMS 实测值为 `data/compound_*.csv`：
   - compound_A/B（文献编号 12a/12b）：TBAF/AcOH 脱 TIPS 保护得到端炔的产物；
   - compound_C（文献编号 13）：12a 与新鲜制备 Cp2TiCl（0.3 M THF）室温反应
     得到的串环化产物。
   另附 compound_C 的实测相敏 NOESY 谱图 `data/compound_C_noesy.png`（原始文件
   7-noesy-2，含 1D 1H 投影）：NOESY 为图像数据，只作为考生推断 C 相对构型的依据，
   不参与脚本判分。
   转录时做了去标识化：① 峰表不含文献与化合物编号，化合物改称 compound_A~C；
   ② HRMS 只保留实测 m/z 与离子类型（A/B 为 [M]+，C 为 [M+H]+），删去文献中 calcd 的元素组成，
   使“分子式正确”得分点需要考生自行由精确质量确定；
   ③ IR、Rf、物理状态与实验操作文字不入数据文件，不参与判分。
   参考 SMILES 为人工描绘并经 RDKit 校验的标准答案。
2. **质量自洽核验**（RDKit 计算）：参考结构的单同位素质量（[M+H]+ 加质子精确质量
   1.007276 Da）与数据文件实测 m/z 的偏差均 ≤ 2.5 ppm：

   | 化合物 | 分子式 | 离子 | 计算 m/z | 实测 m/z | 偏差 |

   | A | C15H20O4 | [M]+ | 264.1362 | 264.1362 | 0.0 ppm |

   | C | C15H22O4 | [M+H]+ | 267.1591 | 267.1597 | −2.3 ppm |

3. **氢计数核验**：各化合物 1H 积分之和恰等于分子式氢原子数（A: 20、B: 22、C: 22）。
4. **立体**：化合物均为外消旋合成。A/B 的谱图不含足够构型信息，只考构造；
   参考 SMILES 中 A/B 的立体标注仅为描绘习惯，不参与判分。C 参考 SMILES 给出其中一个
   对映体的完整立体标注（6 个手性中心），其相对构型与 NOESY 谱一致；
   **判分对“参考构型”与“整体镜像构型”等价给分**（见第三节）。

## 三、判分口径与等价答案规则

1. **得分点一~五由脚本从提交的 `smiles` 列重算**，不看任何申报值；`inchikey` 只用于 tool 表的自洽性得分点。
2. **构造等价规则（以 InChI 为准）**：任意合法写法均可，判分前对提交与参考结构分别
   去除全部立体信息后计算标准 InChI，逐字比对。**不用 SMILES 字符串比对**：
   桥环/稠环体系的环遍历起点与分支写法千变万化，InChI 才是真正规范的构造表示。
   因此换环遍历起点、换分支顺序、Kekulé 写法差异均不影响判分。
3. **立体等价规则（仅 compound_C；对映体等价、非对映体判错）**：
   - 先检查立体完整性：提交结构已指定的立体元素数（四面体手性中心）不少于参考结构
     （6 个）；不足即判错（防"不写立体碰运气"）。
   - 再比对含立体标准 InChI：等于参考 InChI，或等于**参考的镜像 InChI**（脚本把参考结构
     全部四面体手性中心取反后重算；标准 InChI 表现为 `/t` 层相同、`/m` 标志取反），
     二者命中其一即立体正确。
   - 任何非对映异构体（翻转部分手性中心或整体构型错误）的含立体
     InChI 与两个基准都不同，判错。
   - compound_A/B 不判立体：构造判分先去除全部立体，提交写或不写立体均不影响得分。
4. **分子式**：`rdMolDescriptors.CalcMolFormula` 逐字比较（去立体后计算，与立体标注无关）。
5. **环数目**：图论环数（键数 − 原子数 + 1）；参考值 A=2、B=2（脂环 + 环氧），C=3（三环）。
6. **官能团**：五类特征（羧酸酯 ester_COO、非环烯烃 alkene_C=C、炔键 alkyne_C#C、
   环氧 epoxide、羟基 hydroxyl_OH）的计数逐一相等才算对，定义见两份评分表的得分点三；
   参考计数见 `reference_values.json` 的 `functional_group_counts`。
   C 的环外亚甲基（=CH2）不计入非环烯烃：=CH2 碳非 X3，且桥头/环内双键本就不在计数范围。
7. **化合物一一对应**：`compound_id` 与数据文件、参考结构直接对应，无组内调换；
   `compound_id` 大小写与空白做宽容化处理（如 `compound_a`、`A` 均可识别）。
8. **InChIKey 自洽性（tool 表得分点六）**：按提交 SMILES **原样**（含考生写的任何立体标注）
   重算标准 InChIKey，与申报值比较（忽略大小写）。只判自洽、不判正确：结构错但标识符与
   自己的 SMILES 对得上照样得分；三个化合物全部对不上时脚本触发 FAIL。
9. **NOESY 数据**：`data/compound_C_noesy.png` 为图像数据，只作为考生推断 compound_C
   相对构型的依据，不参与脚本判分；立体判分完全基于 InChI 比对。
10. **分值折算**：本题 3 个化合物，单位分值按总分 100 分配：分子式 5、环数 5、官能团 5、
    构造 10（每化合物），立体 25（no_tool，仅 C）/ 19 + InChIKey 2（tool，每化合物），
    每表合计均为 100。

## 五、判分参数汇总

- 输出文件：`output/structures.csv`，表头 `compound_id,smiles,inchikey`，3 行。
- no_tool：分子式 5×3 = 15，环数 5×3 = 15，官能团 5×3 = 15，构造（去立体 InChI）10×3 = 30，
  立体（仅 C，参考或对映体含立体 InChI）25×1 = 25，合计 100。
- tool：分子式 5×3 = 15，环数 5×3 = 15，官能团 5×3 = 15，构造 10×3 = 30，立体 19×1 = 19，
  InChIKey 2×3 = 6，合计 100。
- FAIL 触发条件：提交件缺失；任一化合物缺行；SMILES 缺失/不可解析；
  全部 InChIKey 与自身 SMILES 不符（仅影响 tool 表得分点六的证据认定）。
